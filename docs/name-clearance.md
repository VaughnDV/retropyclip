# Name clearance

Reviewed on 16 August 2026. This is an engineering clearance note, not legal advice.

## Package and repository names

| Name | Result |
|---|---|
| PyPI `retropyclip` | Unclaimed (HTTP 404 on the project JSON API) |
| PyPI `retro-py-clip` | Unclaimed |
| PyPI `retropy-clip` | Unclaimed |
| GitHub `retropyclip` | No unrelated public repository collision found for this exact name |
| PyPI/GitHub `pyclip` | Existing clipboard *library* (Apache-2.0). Different product, similar stem |

`RetroPyClip` / `retropyclip` is distinctive enough to use publicly and as the Python distribution name. The closest confusion risk is `pyclip`, a low-level clipboard access library rather than a history/sync application.

## Trademarks

No live USPTO registration for the exact mark "RetroPyClip" was found in a public web search. Generic "clipboard" marks exist and are largely expired or unrelated. A formal trademark search is still recommended before commercial branding, paid ads, or a macOS App Store listing.

## Decision

Keep `RetroPyClip` as the public project and PyPI name for the alpha. Mention `pyclip` in contributor docs so the names are not treated as interchangeable. Revisit before any trademark filing or paid distribution.
