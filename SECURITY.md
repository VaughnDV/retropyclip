# Security policy

RetroPyClip handles clipboard data, which should always be treated as sensitive.

## Supported versions

This project is an early prototype. Only the newest commit is supported until a
stable release exists.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Contact the repository
owner privately with a description, reproduction steps, affected version, and
any proposed mitigation. Allow a reasonable remediation window before public
disclosure.

Never include real passwords, OAuth tokens, recovery codes, or clipboard contents
in a report. Use synthetic data when demonstrating an issue.
